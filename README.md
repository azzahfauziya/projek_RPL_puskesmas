# Puskesmas Sehat

Aplikasi manajemen klinik (Puskesmas) berbasis web — dikembangkan sebagai proyek Rekayasa Perangkat Lunak (RPL) dengan studi kasus dummy client seorang perawat di lingkungan puskesmas.

## Demo Live

🔗 [https://puskesmas-sehat.infinityfreeapp.com/](https://puskesmas-sehat.infinityfreeapp.com/)

## Deskripsi

Puskesmas Sehat adalah sistem informasi yang membantu proses administrasi, pelayanan medis, dan pengelolaan obat di puskesmas secara digital. Aplikasi ini mendukung alur kerja multi-role mulai dari pendaftaran pasien, antrian, pemeriksaan dokter, hingga pengambilan obat di apotek.

## Tech Stack

- **Backend:** Laravel
- **Frontend:** Vue 3 + Inertia.js
- **Styling:** Tailwind CSS
- **Database:** MySQL

## Role Pengguna
Aplikasi ini memiliki 4 role dengan hak akses dan dashboard masing-masing:

| Role | Akses Utama |
|---|---|
| **Administrasi** | Pendaftaran pasien, manajemen antrian, billing, dan kwitansi pembayaran |
| **Dokter** | Pemeriksaan pasien, riwayat kunjungan, input diagnosa dan resep |
| **Perawat** | Pencatatan data vital pasien, bantu alur pemeriksaan, riwayat pasien |
| **Apoteker** | Pengelolaan stok obat, validasi & penyerahan resep ke pasien |
